# AI-provenance disclosure

Put a short paragraph near the end, after License. Say the facts a reader needs to weigh the code: who wrote it, and who reviewed it (or what checks stand in for review).

In Kerrick Long's own projects, or where the maintainer has no house pattern and approves it, use three terms, defined once with this exact quote. Otherwise use the maintainer's wording.

> I use three words for how code and prose comes to exist. Code or prose I wrote, I typed by hand, with nothing generated. Code or prose I wrought, an AI agent generated while I iterated with it, and I reviewed every change before committing it, so I take responsibility for every diff. Code or prose I requested, an agent built with little or no review from me, in the style of a "dark factory."

Also assess the project according to [declare-ai](https://declare-ai.org/1.0.0/assess.html). Be clear about both axes: wrote, wrought, or requested; and none, total, creative, and non-creative.

Rules:

- Use the maintainer's existing wording and any existing disclosure in their other projects. Ask which category applies. Never assume.
- Say which parts fall in which category. Do not give one blanket label unless true.
- Do not apologize. Do not boast.
- Keep it to a short paragraph. Link to a longer policy if there is one.
