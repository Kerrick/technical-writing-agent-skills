# 1. Recall

The first message of a new session, before any skill or file is in context. It primes the model's own knowledge of the field.

```
Without reading files, using tools, or etc. like that, think of EVERYTHING you can remember about technical writing, developer documentation, pedagogy, learning, and the like. All of the related fields necessary to write a programming book, script a tutorial video series, write API reference docs and/or guides, and the like. Don't repeat them to me, just think of it all. Then say OK.
```
